# Bills Manager - 产品需求文档 (PRD)

---

## 1. 产品概述与定位

### 1.1 产品简介
**Bills Manager** 是一款专为 iOS 平台（iOS 17.0+，支持 iPhone 与 iPad）设计的**本地优先 (Local-First) 个人财务账单管理与到期提醒应用**。产品专注于“账单追踪与到期防漏”这一核心场景，帮助用户精准管理周期性支出（如房租、水电网费、信用卡账单、订阅服务、贷款等），避免因逾期产生罚金或信用受损。

### 1.2 目标用户画像
1. **多订阅/多账单人群**：拥有多项数字订阅（Netflix、iCloud、Spotify 等）及日常固定账单，容易忘记扣费日。
2. **注重财务隐私者**：不愿绑定银行账号、不愿上传数据至第三方服务器，追求数据完全本地掌控的用户。
3. **多设备用户**：同时使用 iPhone 与 iPad，需要在不同设备尺寸上获得极致原生体验的用户。

### 1.3 核心痛点与解决方案
| 痛点 | Bills Manager 解决方案 |
| :--- | :--- |
| 账单分散，容易忘记还款导致逾期罚款 | 集中管理 + 本地静默/强提醒 + 图标角标 (Badge) |
| 订阅服务自动扣款不知情 | 支持 Auto-Pay 标识，扣款前提前预警 |
| 财务应用功能冗余（记账/理财广告多） | 聚焦账单追踪，无第三方广告，界面纯粹 |
| 数据隐私泄露风险 | 数据全量存储于本地 SwiftData，支持 Face ID 锁屏保护 |

## 3. 功能需求矩阵 (Functional Requirements)

### 3.1 账单管理核心模块 (Bill Management)
1. **新建/编辑账单**：
   - 输入属性：账单名称（必填）、金额（必填）、到期日、分类、支付账户、重复周期、Auto-Pay 状态、提前提醒天数、提醒时刻、备注、小票图片附件。
   - 重复周期选项：一次性 (Once)、每天 (Daily)、每周 (Weekly)、每两周 (Bi-weekly)、每月 (Monthly)、每双月 (Bi-monthly)、每季度 (Quarterly)、半年 (Semi-annually)、每年 (Yearly)。
   - 自定义重复截止日期：支持设置账单循环结束的时间。
2. **状态流转引擎**：
   - 自动依据当前日期与到期日判定状态：`Overdue` (逾期)、`Due Today` (今日到期)、`Due Soon` (3天内到期)、`Upcoming` (正常未到期)、`Paid` (已支付)。
   - 划归已付操作：手动点击或左划将账单标记为已付。对于周期账单，标记已付后自动将到期日滚动更新至下一个周期。
3. **支付历史 Log**：
   - 记录每次划归已付的时间、实付金额、交易流水号/凭证参考码及小票照片。

### 3.2 多维度视图模块 (Views & Navigation)
1. **仪表盘 (Dashboard)**：
   - 顶部逾期红色预警 Banner（包含逾期账单数与总逾期金额）。
   - 4 大指标卡片：本月应付、逾期金额、本月已付、未结账单数。
   - “即将到期”与“近期账单”列表快捷操作。
2. **账单列表 (Bill List)**：
   - 分栏 Filter：全部 (All)、已逾期 (Overdue)、未支付 (Unpaid)、已支付 (Paid)。
   - 分类 Capsule 滚动筛选器与模糊搜索框。
   - 支持 Swipe Actions：左划标记支付/取消支付，右划编辑/删除账单。
3. **交互日历 (Bill Calendar)**：
   - 月度网格日历，按账单状态显示彩色指示圆点（红/橙/黄/蓝/绿）。
   - 点击日历任意日期，下方列表即时联动展示该日期的账单明细。
4. **Swift Charts 数据分析 (Analytics)**：
   - 时间区间选择：本月、近3个月、今年、历史全部。
   - Swift Charts (`SectorMark`) 环形图展现支出分类分布，配合分类明细比例表。

### 3.3 账户与分类管理 (Categories & Accounts)
- **分类管理**：自定义分类名称、SF Symbol 图标与 Hex 颜色。
- **账户管理**：管理信用卡/储蓄卡/现金账户，记录尾号与专属颜色。

### 3.4 安全与系统设置 (Security & Settings)
- **Face ID / Touch ID 锁**：切换开启生物识别保护，退至后台自动遮罩。
- **数据导出/备份**：导出标准 CSV 文件，生成 JSON 数据库备份文件。

## 4. 非功能需求 (Non-Functional Requirements)

1. **性能与响应速度**：
   - 冷启动时间 $< 0.8$ 秒。
   - 列表滑动帧率维持在 60fps / 120fps (ProMotion)。
2. **数据离线与本地优先**：
   - 无需注册登录，无需联网即可使用全部核心功能。
3. **兼容性与适配**：
   - 最低支持系统：iOS 17.0。
   - 设备适配：iPhone (所有屏幕尺寸) 与 iPad (包含 Split-View / 多任务分屏)。
